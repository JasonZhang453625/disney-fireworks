# 🏰 Disney Magic Kingdom Fireworks · 梦幻城堡烟花盛典

基于 HTML5 Canvas 和 Web Audio API 构建的沉浸式迪士尼梦幻城堡烟花秀。

## ✨ 特色亮点
1. **完整序曲前摇（Act I & Act II）**：奇迹序曲、小飞侠金粉流星、浪漫双塔礼花、城堡梦幻灯光。
2. **狂潮爆发与终极璀璨（Act III & Act IV）**：超高频连续轰鸣烟花狂潮、锦冠金柳雨（Kamuro Willow）、千朵礼花齐聚城堡之巅。
3. **Web Audio API 真实声效合成**：升空啸叫、低音重炮轰鸣、龙蛋噼啪爆裂、迪士尼梦幻八音盒旋律。
4. **互动控制**：支持点击屏幕任意位置发射定制烟花、一键跳过前摇直接进入高潮、狂暴连发模式、全屏沉浸体验。
5. **极速部署**：纯前端静态架构，零依赖，支持一键部署至 Vercel / GitHub Pages。

## 🚀 本地运行
直接双击 `index.html` 或通过任何静态服务器（如 Live Server、Vite、http-server）打开即可。
